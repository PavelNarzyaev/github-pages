# Фрирайтинг GPT

Статическая страница для чтения. Без сборки, библиотек, внешних шрифтов и сетевых запросов. Текст находится прямо в HTML и доступен без JavaScript. Можно открыть `index.html` с диска.

## GitHub Pages

1. Загрузите `index.html`, `styles.css` и `script.js` в корень репозитория.
2. В **Settings → Pages** выберите **Deploy from a branch**, ветку с файлами и папку **/ (root)**.
3. Сохраните настройки. После публикации ссылка появится в разделе Pages.

Все пути относительные: страница работает и в репозитории проекта, и на основном домене GitHub Pages. Исходный `.txt` для работы страницы не нужен.

## Чтение

Кнопка «Аа» открывает выбор оформления, шрифта и размера текста. Настройки и место чтения сохраняются в браузере на текущем устройстве. При следующем открытии кнопка «Продолжить чтение» возвращает к сохранённому абзацу. Если браузер запрещает локальное хранение, текст и настройки остаются доступны, но не сохраняются между посещениями.

Чтобы изменить текст, отредактируйте абзацы внутри `<article id="text">` в `index.html`. Время чтения рассчитывается автоматически.
